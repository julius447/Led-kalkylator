# LED Calculator — WordPress / Fluent Snippets package (for Chris)

This ZIP is the **WordPress-native, paste-ready** version of Ampy's LED savings calculator. It is a **1-to-1 clone** of the live prototype — https://julius447.github.io/Led-kalkylator/ — every font, weight, colour, gradient, spacing value and micro-interaction is byte-for-byte identical. Only the *packaging* differs (3 Fluent Snippets instead of theme/plugin files).

> **Language note:** all developer-facing material — this guide, the install steps, and every code comment — is in **English**. The **on-screen text stays Swedish on purpose** (this is a Swedish lead magnet; the visitor-facing copy, labels and the lead email are Swedish). That is correct and intended, not a leftover.

## What's in here

| File | What it is |
|------|-----------|
| **`README-FLUENT-SNIPPETS.md`** | **The install guide — read this.** 4 steps, ~10 minutes. |
| `HANDOVER.md` | **Reference only** — every number, the formulas + a worked example, GDPR, analytics, accessibility, QA. Read it to understand *what the tool does*. ⚠️ Ignore its install steps (§0/§4/§14 describe an older theme-enqueue path); install via `README-FLUENT-SNIPPETS.md`. |
| `1-ampy-led-styles.css` | Snippet 1 of 3 — paste as a Fluent **CSS** snippet. |
| `2-ampy-led-scripts.js` | Snippet 2 of 3 — paste as a Fluent **JS** snippet. |
| `3-ampy-led-shortcode.php` | Snippet 3 of 3 — paste as a Fluent **PHP** snippet. |

> **Provenance:** the three snippets are generated by pure concatenation of the prototype's source files (CSS/JS) and by embedding the prototype markup verbatim (PHP). The generator (`build-snippets.js`) and the sources live in the repo: https://github.com/julius447/Led-kalkylator (`wordpress-fluent-snippets/`). You do not need them to install — the three files here are complete.

## The 30-second version

1. Create three Fluent Snippets: **CSS** (`1-…css`), **JS** (`2-…js`), **PHP** (`3-…php`) — paste each file, activate.
2. Put the shortcode `[ampy_led_kalkylator]` in a Bricks **Shortcode** element where the calculator should appear.
3. Run the QA checklist at the bottom of `README-FLUENT-SNIPPETS.md`.

Full detail — run conditions, per-page presets, the optional lead endpoint, fonts/GDPR, and QA — is in **`README-FLUENT-SNIPPETS.md`**. Start there.
